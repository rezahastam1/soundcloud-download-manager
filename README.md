امکان استفاده اختیاری از Free Download Manager

قابلیت بی‌صدا کردن و رد کردن خودکار تبلیغات در زمان پخش

نصب

فایل‌های پروژه را دانلود کنید.

در Chrome آدرس زیر را باز کنید:

chrome://extensions

گزینه Developer mode را فعال کنید.

روی Load unpacked کلیک کنید.

پوشه اصلی افزونه را انتخاب کنید.

ساختار اصلی پروژه

manifest.json — تنظیمات افزونه

background.js — مدیریت دانلود و ارتباط با SoundCloud

content.js — رابط افزونه داخل صفحات SoundCloud

ad-engine-main.js — مدیریت تبلیغات هنگام پخش

inject.css — استایل پنل داخل SoundCloud

popup.html / popup.js / popup.css — پنجره اصلی افزونه

offscreen.html / offscreen.js — پردازش فایل و دانلودهای HLS

نکته

این پروژه برای استفاده شخصی و آموزشی توسعه داده شده است. مسئولیت استفاده از افزونه و رعایت قوانین SoundCloud بر عهده کاربر است.
